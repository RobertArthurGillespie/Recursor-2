RECURSOR ENGINE — DEVELOPMENT ROADMAP (CURRENT STATE)

OVERVIEW
Recursor is an adaptive training engine that:
- captures user telemetry from simulations
- builds behavioral state representations
- applies adaptive interventions
- evaluates outcomes
- learns which interventions work, under which conditions, over time

The system evolves in layers:
1. Behavior understanding
2. Adaptation control
3. Policy learning
4. Temporal intelligence (in progress)
5. Continuous learning (future)

--------------------------------------------------
PHASE 1 — CORE ADAPTIVE LOOP (COMPLETE)
--------------------------------------------------
Telemetry → Feature Windows → Behavior Profiles → Hypotheses → Adaptation

- Unity emits telemetry events
- .NET backend builds feature windows
- Behavior interpreter produces dimension scores
- Adaptation policy generates interventions
- Adaptations returned to Unity

PHASE 10 — TEMPORAL INTELLIGENCE (IN PROGRESS)
--------------------------------------------------

PHASE 10A — SEQUENCE-AWARE FEATURES (COMPLETE)
- Sliding window (last N windows)
- Trend slopes (confusion, goal, hint)
- Volatility detection
- Momentum signals
- Stability scoring
- Near-term risk classification
- ADX ingestion + API exposure

PHASE 10B — TEMPORAL EMBEDDINGS (NEXT)
- Fixed-length embedding vector per window
- Combines:
  - current state
  - sequence features
  - trajectory signals
  - guardrail state
  - adaptation context
- Stored in TemporalEmbeddings table
- Training targets stored in TemporalPredictionTargets table
- No deep learning yet

PHASE 10C — TEMPORAL PREDICTION MODELS (FUTURE)
- Train models on embedding + target tables
- Predict:
  - next behavior state
  - next-N window trajectory
- Potential models:
  - LSTM / RNN
  - Transformer encoder
- Introduce trajectory-aware adaptation
